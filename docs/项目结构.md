# 项目结构

本仓库包含**两个部署单元**，各自一个 Dockerfile、一个容器镜像。

```
                      公网                             内网
             ┌──────────────────────┐      ┌──────────────────────┐
 浏览器 ────►│  fdn (front desk node)│      │  tunnelagent          │
             │  静态 + 信令 + 兜底反代  │      │  出站连信令 + 反代       │
             └──────────────────────┘      └──────────┬───────────┘
                    ▲                                 │
                    └──── P2P DataChannel ────────────┘
                          （业务流量直达，不过公网）
```

---

## 1. `fdn` — front desk node（公网边缘）

一个进程、一个端口，同时提供三件事：

| 路径 | 作用 |
| --- | --- |
| `/__lan/*` | 覆盖层资产：Service Worker、连接页、holder、`config.json` |
| `/__lan/ws` | 信令 WebSocket（只做 SDP/ICE 配对，**不转发业务流量**） |
| 其余路径 | **兜底反向代理**：按路由表转发到内网 |

兜底代理内置在容器里，**取代宿主机 nginx vhost**——公网边缘只需一个容器，没有第二处要同步的路由配置。

- 目录：`fdn/`（Dockerfile）、`fdn/web/`（前端源码与构建）、`agent/cmd/fdn/`（入口）、`agent/internal/fdn/`（服务实现）
- 端口：`:8080`（资产 + 信令 + 兜底共用）
- 路由表：`fdn` 启动时用 `-routes routes.yaml` 指定；不给则只提供资产与信令

## 2. `tunnelagent` — 内网代理（内网侧）

部署在内网，**主动出站连接信令，不监听任何端口**。收到浏览器请求后按路由表转发到内网服务。

- 目录：`tunnelagent/`（Dockerfile + `routes.yaml`）、`agent/cmd/tunnelagent/`（入口）、`agent/internal/tunnel/`（隧道与转发）
- 路由表：`tunnelagent/routes.yaml`

## 代码布局

```
.
├── fdn/
│   ├── Dockerfile           # 公网边缘镜像
│   └── web/                 # 浏览器侧全部前端（Vite + TS + SW）
│       ├── src/
│       ├── public/config.json
│       └── *.html
├── tunnelagent/
│   ├── Dockerfile           # 内网代理镜像
│   └── routes.yaml          # 内网路由表
├── agent/                   # 一个 Go module，两个 cmd/
│   ├── cmd/fdn/             # fdn 入口
│   ├── cmd/tunnelagent/     # tunnelagent 入口
│   └── internal/
│       ├── fdn/             # 静态 + 信令 + 兜底反代
│       ├── tunnel/          # WebRTC 隧道、多路复用与请求转发（tunnelagent）
│       ├── relay/           # 路由表 + 反向代理（两边共用）
│       ├── signaling/       # 信令服务端与客户端
│       └── protocol/        # 信令消息定义（两边共用）
├── scripts/                 # 本地开发栈（dev-stack.sh）与 STUN 探测工具
└── docs/
```

### 为什么是一个 module + 两个 cmd

两边共享 `protocol`（信令消息）与 `relay`（路由语义），拆成两个 module 只会把同一份代码复制两遍或引入版本协调。一个 module、两个 `cmd/` 已经足够让两个镜像各自只装自己的二进制。

## 与浏览器的契约

| 路径 | 归属 | 说明 |
| --- | --- | --- |
| `/__lan/sw.js` | fdn | Service Worker（scope `/`） |
| `/__lan/connect.html` | fdn | 连接页 |
| `/__lan/holder.html` | fdn | 常驻 iframe |
| `/__lan/config.json` | fdn | 运行时配置 |
| `/__lan/ws` | fdn | 信令 WebSocket |
| `/api/*` | tunnelagent（经隧道） | 命中 `apiPrefixes` 且不在 `neverTunnel` 内；默认包含认证接口 |
| 其余 | fdn 兜底反代 | 静态资源 |
